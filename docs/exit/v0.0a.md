## Deviations from the plan, and things to know

- **Probe workload.** There is no flight model yet, so the hash covers a 32-body probe world (not 64
  as first sketched) with every transcendental, RNG draws and quaternion integration (ADR-23).
- **Licence allow-list** gained `Zlib` (ADR-21).
- **TypeScript is 6.0.3, not 7**, because typescript-eslint does not support 7 yet (ADR-21).
- **A real bug surfaced on the first CI run, and is fixed.** The offline test failed in CI (both
  attempts) while passing locally on installed Chrome. Cause: the Service Worker cached assets from
  requests it built itself, which carry no `Origin` header, but Chromium's headless shell sends
  `Origin` on the page's same-origin `crossorigin` module and stylesheet requests, and the preview
  server answers `Vary: Origin`, so every `Cache.match` missed. Online this was invisible (a miss
  fell through to the network); offline the reload had no scripts. Fix `12b4534`: `ignoreVary` on
  every lookup. This also explains the one unexplained local flake noted earlier. Lesson: run
  Playwright on the bundled Chromium locally (the CI browser), not only on installed Chrome.
- **Browser coverage.** CI and local runs now both use Playwright's Chromium headless shell. Firefox
  and Safari are not exercised yet.
- **Not covered by v0.0a (by design, v0.0b):** the 60 Hz loop, snapshot buffer, renderer, input,
  compat-check screen, debug overlay, content baker, extension seams, performance harness, and runs
  on the three reference machines.
- **The repository is public** and carries an all-rights-reserved licence until OQ-04 is decided.
