# packages

TypeScript workspace (GDD §61.2–§61.3). Tiers, low to high (enforced by dependency-cruiser):

| Tier | Package | What |
|---|---|---|
| 1 | `platform-web` | feature detection, URL flags, key-value store, metrics, logging, the WASM loader, Service Worker, shared-memory ring and seqlock |
| 2 | `sim-bridge` | generated byte layouts, input and snapshot codecs, the two channel implementations, the typed handle on the sim module, worker messages |
| 3 | `sim-host` | the Sim Worker: fixed-step clock, sleepers, loop, client |
| 3 | `input` | keyboard and gamepad, the shaping pipeline, the input pump |
| 3 | `render` | the `Renderer` seam, WebGPU and WebGL2 backends, WGSL, camera, interpolation, the Render Worker |
| 3 | `audio` | the `AudioBackend` seam and its null implementation |
| 4 | `perf` | PS-0, gates, the first-run benchmark |
| 5 | `ui` | compat check, screens, debug overlay, panels, game-flow reducer, strings |
| 6 | `app-shell` | the composition root, Vite config, Service Worker entry, self-tests |
| — | `tools` | build-time scripts: WGSL preprocessing and GLSL generation, manifests, reference-machine runs |

The map of what runs where is [docs/architecture/runtime.md](../docs/architecture/runtime.md).

Reserved names (not created yet): `hud`, `map`, `terrain-stream`, `world-render`, `net-transport`,
`lobby-ui`.
