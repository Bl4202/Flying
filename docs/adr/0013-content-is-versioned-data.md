# ADR-13: Content is versioned data

- **Status:** Accepted
- **Owner:** Bl4202
- **Source:** GDD §0.4 (imported verbatim at v0.0a)
- **Affects:** §62

## Decision

**All content is versioned data** (JSON authoring → baked binary), never code.

## Alternatives considered

Hard-coded content tables

## Rationale

Outline §115 and §147: adding content must not require engine changes; supports modding and user content.
