## Known, outside this milestone

- **WebKit in CI** (`e2e-compat`, since v0.1a; informational). The cause: WebKit on the CI's Linux runner passes
  the compat check's WebGL2 probe (made on the page) but cannot give the render worker a WebGL2 context, so the
  game stops with its clean `SYS-103` screen. It is the runner and not the game: the same spec passes on WebKit
  (Playwright 2370) and Firefox 157 on the M4 (2026-11-08), where the game boots and ticks. The spec now skips
  with that reason on a `SYS-103` stop and still fails on any other stop or a hang. Not done: the compat probe
  could run in a worker, so that it says what the renderer will find (on that runner it says OK and the
  renderer then fails).
- No machine of the GDD's Recommended spec has been tested; the M4 gates (owner decision).
- **Cut from the plan, as its cut list allows:** SSIM image goldens (S6; ADR-39 amendment 1); gear-motion,
  touchdown and airbrake sounds; HUD palettes beyond green and high-contrast are built, auto-brightness is not;
  the chase camera's horizon-level option and cross-fade; joystick second-hat and gamepad look (the gamepad's
  right-stick press cycles the camera); geomorphing between terrain levels (skirts hide the seams); a menu
  backdrop scene.
- **Built differently from the plan:** without cross-origin isolation the sound is fed from the 4 Hz stats, not
  a 30 Hz `audio-feed` message from the sim worker; an end-to-end spec for L0 re-centring during a flight was
  dropped (unit tests cover it); the HUD's CPU time is not a field of the arena report and the HUD's GPU pass time
  is not measured (U3's readings); AC-53.4's main-thread UI scripting time is not measured.
- **Polish:** the cockpit's glare shield and panel look heavy; the exterior is untextured low poly.
- **Test strength:** the camera rig's and model rig's allocation harnesses pass one small array a frame (ADR-39
  amendment 2).
- **CI:** the thread specs failed twice on frame counts with the new scene on the software rasteriser before
  they were given a floor instead of a speed (ADR-39 amendment 2); the first merge's `e2e` run failed on them
  and was re-run. `staging-smoke` had the same fault in its own frame assertion and failed on `c45bf85` until PR #13.
