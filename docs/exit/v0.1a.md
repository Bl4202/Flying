## Deliberate faults (2026-10-15, not committed)

Each check was broken once on purpose to show that it catches its fault. Every file was restored
afterwards, and the clean tree passed again.

| Fault | Caught by | Result |
|---|---|---|
| `f64::sin` in `flight` | clippy | `disallowed method f64::sin: use simmath::dmath::sin (ADR-10)` |
| A `Vec` allocated in `step_tick` | `no_alloc` | 1 000 allocations in 1 000 ticks of flight |
| `C_mδe` sign flipped | trim tests | `a_level_trim_converges_and_holds`, `the_trimmed_cl_max_is_c4s` fail |
| α grid not monotone | baker | `/lift/cl_base/x/11: the x grid is not strictly increasing`, with the fix |
| Post-stall blend starting at the lift peak | baker blend lint | `at Mach 0 the blend starts at 31.62 deg, within 5 deg of the lift peak at 32 deg` |
| `"core:ac/kestrel"` in `sim-core`, `F129_…` in `flight` | `check-content-ids` | both reported with file and line |
| One flight60 segment changed (pitch 0.5 to 0.4 over 10–15 s) | `determinism` | flight60 diverges from the golden at tick 660; erratic unaffected |
| Wave drag +10 % | `conformance` | **Not a failure.** `vmax_sl` moves from +0.72 % to −2.94 %, inside ±3 %, and the run warns that the point uses 98 % of its tolerance. At +12 % the gate fails (−3.58 %). In both cases the static cross-check agrees within 0.04 %. The gate catches drag errors from about +11 % of wave drag; smaller ones show up as the over-60 % warning |
