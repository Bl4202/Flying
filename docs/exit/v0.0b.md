## Reference machine runs

Scripted with `pnpm perf:local` against the staging build `7e1e394` (runbook:
`docs/runbooks/reference-machines.md`). Each folder holds `summary.md`, `compat.json`, `flight.json`,
`flight.png`, `benchmark.json` and `perf-ps0.json`. Pass criteria: compat verdict not fatal, strict
PS-0 gates for 120 s, no errors or device loss, and at least 30 FPS for a Minimum-class run (display
rate otherwise).

| Run | Machine and path | Result | Evidence |
|---|---|---|---|
| A `m4-webgpu` | Mac (M4, 10 cores), WebGPU on Apple Metal 3, installed Chrome, headed | ✅ pass | sim 60.000 Hz, 0 dropped, tick avg 0.04 ms, p99 0.15 ms; 120.1 FPS on a 122 Hz display, frame p99 9.5 ms; benchmark: 375 k ticks/s on one core, 1.77 M on 8 workers (4.7×), 64 patches at 1080p in 0.86 ms, profile high / preset ultra; no console errors |
| B `m4-webgl2-throttled` | Same Mac, forced WebGL2 (ANGLE on Metal), 4× CPU throttle | ✅ pass | compat `degraded` (graphics row: WebGL2 compatibility renderer), sim 60.000 Hz, 0 dropped, tick p99 0.05 ms; 120.0 FPS, frame p99 9.5 ms; benchmark: 64 patches in 0.76 ms; no console errors |
| C `rtx5060-webgpu` | Laptop, discrete GPU, WebGPU (High class) | ⏳ | to be run by the project owner |
| D `rtx5060-igpu` | Same laptop on the integrated GPU (Minimum-class GPU) | ⏳ | to be run by the project owner |

Run B's throttle is applied to the main thread only (DevTools CPU throttling does not reach
workers), so B shows that the WebGL2 path holds the strict gates and 120 FPS on this hardware, not
that a slow CPU does. That gap is the reason for the Minimum waiver below.

## Approximations and open items

- **Minimum hardware.** Run D has a Minimum-class GPU with a faster CPU and more memory than the
  Minimum; run B has a Minimum-like renderer path but DevTools throttling may not reach workers.
  True 4-core, 8 GB hardware is an open item under a waiver (ADR-28) and does not block the tag.
- **WebGPU in CI.** CI runners have no GPU and the headless browser cannot present WebGPU, so
  WebGPU is proved on real GPUs only (runs A and C). WebGL2 is proved in CI.
- **Benchmark thresholds** are provisional (`packages/perf/src/benchmark/thresholds.json`).
- **Firefox and WebKit** are covered by a non-blocking boot and compat check. On the first CI run
  the compat screen rendered in both; Firefox reported a fatal verdict on the runner (so the game
  was not attempted) and WebKit did not start the game within 30 s, nor within 60 s after the timeout was raised
  (run 38514497211). Both are best-effort at this stage (GDD 0.6.3) and are recorded here rather
  than fixed.
